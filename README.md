# SOL6 Brain Plugin (v3.7.0)

Zero-secret client plugin for Kimi Code/Work, Claude Code/Desktop, Gemini CLI, ChatGPT/Codex, and Antigravity.
Connects to `https://brain.sol6.io/mcp` (auto-org) or `https://brain.sol6.io/mcp/symea` with OAuth 2.1 + PKCE or Bearer PAT.

## Install

- 1-Click Installer: Sign in to `https://brain.sol6.io/app` -> AI Connect & Governance.
- Claude Code: `/plugin install symea-brain --marketplace hugodupont16/symea-brain-plugin`
- Codex CLI: `codex plugin marketplace add hugodupont16/symea-brain-plugin && codex plugin add symea-brain@symea`
